# Contribute and Give Feedback

HuaBu Canvas is developed in the open. The most useful support is concrete feedback, reproducible bug reports, thoughtful feature requests, and improvements to the documentation or code.

## Useful contributions

- Star or watch the [HuaBu Canvas repository](https://github.com/Skl-00/huabu-infinite-canvas) if you want to follow its development.
- Open an issue with a clear reproduction, expected behavior, and actual behavior.
- Propose workflow improvements that help creators arrange prompts, references, assets, and results.
- Improve docs, tests, accessibility, or compatibility with user-configured providers.

Please do not publish API keys, private data, security details, or confidential project material in public issues. Use the [security reporting guide](/docs/support/security) for vulnerabilities.
