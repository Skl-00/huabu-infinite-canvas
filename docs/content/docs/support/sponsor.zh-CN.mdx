# 参与项目与反馈

HuaBu 画布坚持公开开发。对项目最有价值的支持，是具体的使用反馈、可复现的问题、清晰的功能建议，以及对文档和代码的改进。

## 有价值的参与方式

- 在 [HuaBu 画布仓库](https://github.com/Skl-00/huabu-infinite-canvas) 点 Star 或 Watch，跟进项目变化。
- 提交包含复现步骤、预期行为和实际行为的 Issue。
- 提出能改善提示词、参考素材、资产和生成结果组织方式的工作流建议。
- 改进文档、测试、无障碍体验，或对用户自配渠道的兼容性。

请不要在公开 Issue 中提交 API Key、个人数据、安全细节或未公开项目资料。安全漏洞请按[漏洞提交说明](/zh-CN/docs/support/security)处理。
