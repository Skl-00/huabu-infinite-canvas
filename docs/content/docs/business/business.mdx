# Project Cooperation

Open an issue or discussion in the HuaBu Canvas repository if you want to propose a collaboration, custom development, model-provider integration, or a joint AI workflow.

Please include your use case, expected user scale, deployment environment, data and security requirements, integrations, expected delivery scope, timeline, and budget range.

Commercial use is free under the MIT License and does not require a separate license. Please use the repository issue tracker for public, non-sensitive proposals. Do not post private credentials or confidential business data in an issue.
