# 项目协作

如果你希望围绕 HuaBu 画布提出项目协作、定制开发、私有化部署、二次开发或模型渠道接入建议，请优先在仓库的 Issue 或 Discussions 中提出。

## 适合沟通的方向

- 私有化部署、内网部署和团队版落地。
- 定制画布节点、生成流程、素材管理或后台能力。
- 接入自有 OpenAI 兼容接口、模型渠道或提示词仓库。
- 围绕 AI 图片、视频、文本生成工作流做联合方案。
- 技术支持、交付咨询或联合方案评估。

## 建议提供的信息

- 你的业务场景和预期用户规模。
- 需要部署的环境、数据保存方式和安全要求。
- 需要接入的模型、渠道或团队工作流。
- 期望的交付范围、时间和预算区间。

## 提交方式

请通过仓库 Issue 或 Discussions 描述场景、交付范围、时间和预算区间。不要在公开内容中提交 API Key、个人信息或未公开业务数据。

MIT 协议允许免费商用，无需购买商业授权。
