# 卡藏式产品整体 UI 第二阶段计划

日期：2026-09-11

## 目标

把 `D:\codex\HuaBuInfiniteCanvas` 从“各页面分别可用”推进为统一的卡藏式本地创作产品：

- 主页直接进入创作工作台，不再使用营销式首屏作为主要入口。
- 顶部导航、Agent、主题、页面标题、操作区和状态反馈统一。
- 画布库、图片生成、视频生成、素材库、提示词库、配置页使用同一套信息架构和视觉层级。
- 保留现有 API、IndexedDB/localforage、本地资产、画布节点和 Agent 能力。
- 卡藏只作为公开可见交互和信息架构参考，不复制闭源代码、品牌、账号或私有接口。

## 卡藏本轮已观察能力

- 项目库与云端项目分栏，项目搜索、项目更多操作、同步、资源统计、导入导出。
- 顶部项目名称、保存状态、主题、快捷键、设置、任务/积分、账号。
- 画布创建工具、导入素材、3D 导演台、社区卡片。
- 编辑工具、资源库、UI 设置、撤销重做、清空画布。
- 缩放、小地图、定位全部内容。
- UI 设置包含节点样式、界面样式、配色、默认画幅、背景、生成动效和交互连线风格。

## 实施顺序

1. 建立统一产品壳层：页面背景、顶栏、导航、Agent 面板关系、页面内容容器、操作区状态。
2. 主页重做为“项目工作台”：最近画布、快速创作入口、生成历史/素材/提示词快捷入口，避免纯宣传结构。
3. 画布库重做为项目库：项目搜索、最近项目、工作画布数量、导入导出和新建入口。
4. 图片/视频页重组为生成工作台：左侧历史，中间输入与参考，右侧结果；手机端改为抽屉和底部操作。
5. 素材库/提示词库/配置页统一筛选、搜索、分页、操作和空状态。
6. 统一主题变量和响应式断点，补桌面、平板、390px 和短高度验收。
7. 对每个一级路由做功能回归，不以截图通过代替功能通过。

## 第一批工程边界

- 本轮优先完成第 1 至第 3 项，并为第 4 至第 6 项建立稳定壳层。
- 不新增真实云端同步协议，不模拟积分或任务数据。
- 不改变现有生成请求字段、Provider、Agent 通信和本地持久化协议。
- 不自动删除用户的画布、资产、历史或浏览器数据。

## 验收门槛

- 所有一级路由可访问，导航活动态正确，Agent 面板不遮挡主要操作。
- 主页第一屏可直接开始创建画布、图片或视频，不依赖滚动寻找入口。
- 画布库与画布页风格一致，卡藏式项目层级清晰。
- 390px 和 844px 高度下无横向溢出，主要操作可点击，弹层不越界。
- `npm run typecheck`、`npm run build`、`npm test`、`git diff --check` 通过。
- 未验证的云端、Provider 和账号能力明确标记为未完成。
