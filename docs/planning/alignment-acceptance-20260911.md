# HuaBu Infinite Canvas 对齐验收记录

日期：2026-09-11

## 验收结论

本轮已完成以 `basketikun/infinite-canvas` 原生画布为运行底座的基础交互修复、卡藏式工作区布局对齐、多个工作画布管理、整组归档能力和主页入口收口。

这不是卡藏闭源实现的复制，也不代表真实 Provider 生成链路已经验证成功。HuaBuNova/HuaBu 的能力只作为迁移参考，未恢复为本项目运行核心。

## 用户问题对应结果

| 用户问题 | 当前结果 | 证据 |
| --- | --- | --- |
| 拉线无效 | 支持从输入/输出端口开始连接，正向和反向拖动统一为同一语义；重复边不会重复添加；无效目标会取消 | `web/tests/canvas.spec.ts` |
| 右键没有反应 | 空白画布右键打开节点创建菜单，菜单在视口边缘自动调整；节点右键保留节点菜单 | `web/tests/canvas.spec.ts` |
| 点击添加后还要再点画布 | 左侧创建栏点击后立即在当前视口中心创建并选中新节点，同时打开需要编辑的节点面板 | `web/tests/canvas.spec.ts` |
| UI 仍是旧样式 | 增加顶部项目/工作画布区、左侧创建栏、按需资源面板、底部编辑工具和左下缩放控制；节点编辑器受视口约束 | 移动端和桌面截图 |

## 已验证范围

- 桌面视口：1440 x 960。
- 移动视口：390 x 844、390 x 568。
- 工作画布：创建、切换、重命名、复制、删除非主画布、刷新恢复和项目隔离。
- 复制：节点、组关系、连线 ID 重新生成；媒体引用保留；运行中的任务 ID 不继承。
- 归档：整组导出为 ZIP；导入前校验项目、节点、连线和媒体文件；导入后重新映射项目与媒体身份。
- 运行保护：生成请求在途时阻止跨工作画布切换、导入和破坏性导航。
- 代码质量：类型检查、生产构建、Playwright 回归和 `git diff --check` 全部通过。
- 全站巡检：主页、画布库、生图、视频、资产、提示词和配置页面在 1440px、390×844、390×568 下均无横向溢出，巡检脚本收集到 0 条页面错误。

## 保留边界

- 未提交真实 Provider 生成，不消耗用户积分。
- 未声称 Agnes 视频字段、轮询和视频成功链路已经完成验证。
- 资产版本、分镜连续性、交付预检和 CapCut/剪辑交付属于后续能力迁移。
- 未关闭或改动用户已有的卡藏登录标签页；本地应用使用独立内置浏览器标签页验证。
