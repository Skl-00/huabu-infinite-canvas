# 画布能力续作计划

## 目标

继续从真实可操作的画布图协议、生成执行和任务恢复能力审查 HuaBu，不把工作停留在 UI 对齐。重点确保用户从当前画布能创建的连线，和编译器实际消费的连线完全一致。

## 第一阶段

1. 修正 Config 聚合方向：兼容当前 UI 允许的“目标节点 -> Config”连接，同时兼容导入或未来版本的“Config -> 目标节点”连接。
2. 参考栏返回真实断开目标。聚合资源从 Config 展开时，移除资源应断开“资源/组 -> Config”，不能错误断开“资源/组 -> 执行目标”。
3. 增加真实 UI 方向的编译、去重、参考栏来源和断开测试。
4. 审查四类生成入口是否都使用同一编译上下文，找出只显示不执行或执行不持久化的能力断点。

## 第二阶段

1. 审查视频、音频、文本、图片的 Provider 字段和本地媒体恢复。
2. 审查任务中心、刷新恢复、失败/中断/重试和结果节点回写是否保持图语义。
3. 对剩余能力缺口建立可执行的测试或下一轮计划，不用视觉通过替代功能通过。

## 不变量

- 当前画布 UI 能创建的连接必须有真实执行语义。
- 目标节点和 Config 聚合节点都不能把自己作为参考资源发送。
- 组成员直连、组整体连接、Config 聚合连接同一资源最多发送一次。
- 参考栏删除动作必须删除对应的真实连接。
- Provider 成功、任务持久化成功、结果节点回写成功分别有独立证据。
- 不触碰用户已有规划截图改动，不写入凭据。

## 验收

- 目标 -> Config 的真实方向测试通过。
- Config -> 目标的兼容方向测试通过。
- 两种方向的参考栏来源与断开动作测试通过。
- 全量测试、构建和 diff 检查通过。
