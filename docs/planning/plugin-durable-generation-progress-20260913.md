- 插件图片、音频成功和刷新复用已通过；插件失败、部分成功和中断已完成专门浏览器验收。

## 已确认的实现边界

- React Strict Mode 重挂载期间，同一节点同一请求只复用一条进行中任务。
- 节点带有成功任务身份时，插件重新挂载会复用已保存结果，不会再次提交 Provider。
- 节点带有失败或中断任务身份时，插件不会自动重发；显式 `allowRepeat` 才表示主动新尝试。
- 插件文本、视频、图片和音频的成功/刷新复用浏览器定向验收已通过；失败、部分成功、中断和删除目标回写边界已补充验证。真实 Agnes 生产调用、跨设备云同步仍不在本轮证据内。
