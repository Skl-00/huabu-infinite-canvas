# 插件自定义生成 Durable Task 计划

## 目标

把画布插件通过 `ctx.ai` 发起的图片、视频、文本生成统一接入现有 durable runner，使插件调用具备：

- Provider 请求前先保存任务记录；
- 刷新、跨标签和中断后的明确状态；
- 任务中心可查、可定位来源画布；
- 成功结果落入本地图片/媒体存储并回填插件节点；
- 失败和中断不自动重发，重试沿用冻结的原模型绑定；
- 插件脚本、API Key 和原始秘密不进入任务记录、日志或导出。

## 实现边界

1. 复用现有 `startImageRun`、`startVideoRun`、`startAudioRun`、`startTextRun`，不新增平行 `PluginRun` 仓储。
2. 扩展 `CanvasPluginAi` 的可选运行上下文；插件未传上下文时仍可生成，但任务不伪造画布归属。
3. 由 `buildNodeContext` 自动为插件节点绑定 `projectId`、`sceneId`、`targetNodeId`，插件作者无需手工拼接上下文。
4. 插件调用返回值保持兼容：
   - 图片返回已本地化的 `dataUrl` 列表；
   - 视频返回已本地化的 URL、类型和媒体尺寸；
   - 文本保留 `onDelta` 增量回调和最终文本。
5. 任务快照仅保留模型、能力、渠道指纹、请求参数、画布上下文和结果引用；不保存完整脚本或凭据。
6. 视频插件不再依赖模块级内存 Map；其结果由 `VideoRun` 的 pending/localized result 持久化。
7. 插件任务结果回填仅在原节点仍存在且 `generationRunId` 仍指向当前任务时执行，避免旧任务覆盖新内容。
8. 音频插件纳入同一 runner；不改变现有 Agnes 图片/视频/音频串行约束和已有超时边界。

## 分阶段落地

### A. 合同与上下文

- 扩展插件 AI 生成选项和插件宿主上下文类型；
- 宿主注入当前项目、场景和节点信息；
- 记录插件能力和脚本渠道的脱敏指纹；
- 场景复制清理插件任务身份。

### B. 宿主执行迁移

- `use-plugin-host` 的图片、视频、文本调用改走对应 durable runner；
- 增加音频插件调用；
- 把 `onCreated`、`onDelta`、AbortSignal 和结果存储边界接回插件 API；
- 修复视频任务的插件分支，使其不再使用仅内存结果。

### C. 结果与任务中心

- 画布恢复逻辑识别插件任务仍按能力类型投影；
- 任务中心显示插件来源和能力，不改变既有筛选/重试契约；
- 失败、部分成功、中断和本地保存失败保持原有可见状态。

### D. 验证与冷保存

- 单测覆盖上下文绑定、脚本指纹、插件视频刷新边界和失败重试；
- Playwright 覆盖插件节点成功回填、任务中心定位、刷新后结果仍可见；
- 运行 `npm run typecheck`、`npm run build`、全量测试和 `git diff --check`；
- 更新进度、待测清单和变更日志。

## 验收标准

- 插件生成首次请求前，任务记录已能在任务仓储中读取；
- 浏览器刷新不会因为插件调用而自动再次提交 Provider；
- 插件图片/视频/音频结果均有本地存储引用或明确的待处理状态；
- 插件文本增量可见，刷新后至少保留已持久化 partial/final 内容；
- 原配置、模型、脚本或渠道发生变化时，重试明确阻断；
- 场景复制不会让原插件任务回写复制场景；
- API Key、脚本正文和包含秘密的 URL 不出现在持久化任务记录。
