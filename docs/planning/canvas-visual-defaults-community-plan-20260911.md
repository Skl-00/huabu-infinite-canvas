# HuaBu Infinite Canvas 视觉设置与社区入口计划

日期：2026-09-11

## 目标

在 `basketikun/infinite-canvas` 原生项目、节点、连线和本地归档结构之上，补齐一组卡藏式画布工作台需要的项目级控制：

1. 默认生图画幅：新建图片节点时沿用当前工作画布的默认尺寸；已存在节点不被静默改写。
2. 连线显示：允许隐藏持久化连线以便整理画布，但连接进行中和节点编辑语义不被破坏。
3. 设置持久化：新字段在新建、复制、导入、恢复和整组导出中保持一致；旧本地项目按安全默认值运行。
4. 社区入口：主页提供通往现有提示词社区/库的明确入口，不伪造远程社区数据或新增登录依赖。

## 实施边界

- 继续使用 `CanvasProject` 作为唯一项目模型，不引入第二套画布状态。
- 只扩展现有 `CanvasProject`、历史快照、导出导入和画布外观弹层。
- 默认画幅只影响之后创建的图片节点；当前节点的 `metadata.size` 优先级高于项目默认值。
- 连线隐藏只影响已完成连线的渲染与命中区域；活动连接预览始终可见。
- 复用现有 `mediaRatioOptions`，不手写一套互相漂移的比例列表。
- 不调用真实 Provider，不消耗用户积分。

## 工程步骤

1. 增加项目字段、初始化/导入/复制默认值，扩展历史快照和持久化 patch。
2. 在创建节点路径注入项目默认画幅，并用现有尺寸工具保持节点比例。
3. 在画布外观面板加入默认画幅和连线开关，使用主题变量与现有控件。
4. 主页增加社区/提示词入口，并补齐中英文文案。
5. 增加单元/Playwright 验收：默认值作用范围、设置刷新恢复、连线隐藏/恢复、导出字段、桌面与 390px 布局。
6. 更新变更记录、进度和验收文档。

## 验收标准

- 修改默认画幅后，新建图片节点的 `metadata.size` 与设置一致，已有图片节点保持原样。
- 关闭连线后，完成的连接不再可见；重新打开后恢复，刷新后状态不丢失。
- 复制工作画布和 ZIP 导入保留两个项目级设置。
- 主页能从“提示词社区”入口到达现有 `/prompts` 页面。
- `npm run typecheck`、`npm test`、`npm run build`、`git diff --check` 通过。
- 1440px、390px、390x568 页面无横向溢出和控件遮挡。
