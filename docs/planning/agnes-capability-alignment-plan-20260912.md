# Agnes 能力边界对齐计划

## 目标

让 Agnes Video 2.5 Flash 在工作台和画布调用中遵循官方已确认的能力边界，避免 UI 允许提交必然失败的参数：

- `size` 固定发送 `"720P"`。
- `seconds` 限制在 `"4"`–`"12"`。
- `reference` 模式图片最多 5 张，音频最多 3 段。
- Flash 不接受有效参考视频。
- 超出限制时在本地阻止提交，不消耗请求，不删除用户已添加的参考素材。

## 实施

1. 在 Agnes 适配器中集中执行边界校验和请求归一化，覆盖工作台与画布调用。
2. 在视频设置面板根据当前模型展示可用分辨率和秒数范围；参考图入口使用当前模型上限。
3. 保留已有非 Agnes 模型行为，不改变全局超时、轮询、重试和并发策略。
4. 增加受控回归：超限不发请求、旧配置被归一化、合法请求仍使用官方字段。
5. 更新待测试、计划和变更日志，完成类型检查、定向回归和完整回归。

## 对抗性审查

- 不在 UI 层单独防守：适配器必须再次校验，确保画布或 Agent 直调也不会绕过限制。
- 不静默丢弃参考图：超过上限保留素材并给出明确错误，由用户移除后再提交。
- 不把 Agnes 的 720P、4–12 秒限制扩散到 OpenAI、Gemini 或插件模型。
- 不改变已有 Agnes 真实任务，不重复生成；本轮只使用受控假响应。
- 请求尺寸使用模型协议固定值，展示尺寸和最终媒体尺寸仍以实际结果为准。

## 验收标准

- Agnes 超过 5 张参考图或 3 段音频时，POST 次数为 0。
- Agnes 旧配置为 1080p/30 秒时，合法请求发送 720P/12 秒，不发送非法值。
- 非 Agnes 测试继续通过原有请求断言。
- 手机和桌面视频页无横向溢出，测试总数全部通过。
