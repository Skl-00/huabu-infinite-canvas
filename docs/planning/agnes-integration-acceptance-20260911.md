## 官方文档与实测差异

官方依据见计划书列出的 Agnes 自有域名 Markdown。

- 文档排队示例 queued；实际查询返回 pending。现在兼容已验证的 pending，其他未知状态仍明确报错并保留任务。
- 文档完成 URL 位于 metadata.url；实际在顶层 url。仅 completed 状态接收这两种路径。
- 实际 video_id 与 task_id 相同，但实现不依赖二者相同，回归使用不同 ID 验证。
- 生成文件实际尺寸/片长可能与文档表格或请求值不同，UI 与验收使用媒体真实数据，不伪造期望尺寸。
- 视频下载域名 HTTP 200 且为 video/mp4，但没有 CORS 许可。直连首次仅保留远程结果；使用现有本机代理后真正落库，不能把首次远程 URL 当作离线成功。

## 未完成边界

- 用户常用/内置浏览器尚未自动填入密钥：内置浏览器工具认证失败，原生控制因无法可靠确认网址而停止，未绕过。用户可在配置页点击 Agnes Flash，填写 API Key 并保存；需要离线视频时启用本地代理。
- 本地代理来自仓库现有 canvas-proxy，仅监听 127.0.0.1:23210。本轮没有更改超时、轮询间隔/次数或全局并发上限。
- 本地上传图片到 Agnes 视频尚缺经过用户授权的公网媒体托管，不偷偷上传到第三方；目前支持公开链接作为视频参考。
- 视频未迁移到独立 GenerationRun 仓储，跨标签页协调、冻结参数重试、画布全部生成任务接线、任务备份、资产版本、分镜/剪辑交付及全站 UI 继续保留待办。
- 未提交或推送 GitHub。不能将本阶段称为整个产品已完成。
