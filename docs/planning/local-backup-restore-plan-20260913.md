# 本地数据备份恢复计划

## 日期

2026-09-13

## 目标

增加一个不包含 API 配置和凭据的本地数据包，用于迁移或恢复画布工作区：

- 画布项目、工作画布、节点、连线和删除记录；
- 我的资产；
- 图片、视频、音频、文本 durable generation runs；
- 旧版图片/视频工作台历史；
- 任务和画布引用的本地图片、视频、音频文件。

## 设计

- ZIP 根目录使用 `backup.json` 清单和 `files/` 媒体文件。
- 导出前清理 storage-backed 的临时 URL。
- 导入时先完整校验清单和所有文件，再写入媒体与 IndexedDB。
- 导入为“恢复快照”：替换当前画布、资产、任务和旧版历史，不修改 API 配置。
- 所有导入媒体生成新的 storage key，并递归改写所有记录引用，避免覆盖当前浏览器已有媒体。
- 恢复后重新 hydrate 四类任务 store 和资产 store。

## 验收标准

- 导出的清单不含 API Key、模型脚本、Authorization 或 WebDAV 密码。
- 导入后的画布、资产、任务和媒体引用均指向新的本地 storage key。
- 刷新页面后恢复内容仍然存在。
- 无效或缺文件压缩包在写入前被拒绝，不留下半套数据。
- 类型检查、构建、专项浏览器测试和全量回归通过。
