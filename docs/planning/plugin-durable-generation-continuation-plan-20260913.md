# 插件 Durable Generation 续作计划

## 日期

2026-09-13

## 目标

在现有插件图片、视频、音频、文本统一 durable runner 的基础上，完成最后一轮可观察性和反例验收：

- 任务中心明确展示任务来源是独立任务、画布节点还是插件节点；
- 图片多槽位执行遵守已确定的 Agnes 免费模型单请求串行边界；
- 插件图片和音频均完成成功、刷新复用、结果本地化和凭据隔离验收；
- 任务中心从插件失败任务创建重试子任务时继承原始画布/插件上下文；
- 继续保留失败、中断、复制、删除和重试的既有语义，不让测试掩盖真实行为问题。

## 执行步骤

1. 读取当前工作树、插件 durable 计划、反方审查和现有 Playwright 证据。
2. 增加无敏感信息的任务来源投影，覆盖列表和详情。
3. 将图片槽位执行改为串行，保持每个槽位独立记录和部分成功状态。
4. 修复四类 retry runner 的上下文继承，增加插件失败重试来源验收。
5. 增加插件图片、音频及任务中心来源的浏览器验收。
6. 串行执行类型检查、构建和全量 Playwright；失败时只修复本轮明确范围内的问题。
7. 做差异、敏感信息、构建产物和文档审计，更新进度冷存档。

## 验收标准

- 插件任务详情能看到插件 ID、插件节点类型，并保留来源画布入口。
- 图片同一任务的多个 Provider 请求不重叠；每个槽位仍可独立成功或失败。
- 插件图片结果可从 durable run 读取并在刷新后复用，不产生第二次 Provider POST。
- 插件音频结果写入本地媒体存储，刷新后仍可复用，不产生第二次 Provider POST。
- 插件失败任务从任务中心重试后，子任务继续携带原项目、节点、插件 ID 和插件节点类型。
- 任务记录、来源投影和测试证据不包含 API Key、脚本正文或含凭据 URL。
- 不宣称云同步、真实 Agnes 生产成功或超出当前测试证据的能力。
