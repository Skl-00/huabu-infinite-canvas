# 实施前对抗审查

日期：2026-09-11

1. 默认画幅是否会覆盖用户已经调好的节点？不会；只在 `createNode` 生成新图片节点时注入，已有节点和导入节点保持原值。
2. 项目默认值是否会污染全局 AI 配置？不会；字段存于 `CanvasProject`，只作为画布创建时的局部初始值。
3. 老项目没有新字段会否崩溃？不会；读取时使用 `||` 安全默认，导入和复制显式补齐。
4. 隐藏连线是否让画布无法恢复或破坏连接操作？不会；连接数据仍持久化，活动拖线仍渲染，开关只控制已完成连线。
5. 连线隐藏后是否仍会拦截鼠标？不会；完成连线整体不渲染，命中区域自然消失。
6. 历史撤销是否遗漏项目设置？不会；设置纳入现有历史快照，且保存 patch 与快照保持同一字段集合。
7. 复制/导入是否产生第二份或错误的设置？复制从源项目继承；导入直接读取归档字段并给缺失字段安全默认。
8. 社区入口是否暗示已接入真实远程社区？不暗示；只导航到已经存在的提示词库页面，不新增远程 API 或账号能力。
9. 小屏控件是否把外观弹层推出视口？沿用现有 `maxWidth`、`maxHeight` 与滚动约束，并用短视口回归验证。
10. 比例列表是否与生成面板漂移？直接复用 `mediaRatioOptions` 和 `computeMediaSize`，避免重复常量。

结论：范围小、数据边界清晰，可以开始实施；重点检查默认值只作用于新节点、隐藏连线后的活动连接和归档 round-trip。
