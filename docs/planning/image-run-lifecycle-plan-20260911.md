# 图片任务闭环实施计划

## 目标与范围

继续使用 Infinite Canvas 原生 React/Vite/Ant Design/Zustand/localForage 底座。
本阶段解决图片工作台真实生成的生命周期，不宣称视频、画布执行器或 Agnes 协议已经迁移。
主流程：冻结请求 -> 本地落库 -> 提交现有 Provider API -> 逐张保存结果 -> 明确终态 -> 跨页查看/复用/重试。
保留已有历史、协议名、存储键和上游许可；不自动调用用户收费 API，不增加超时/重试/批量上限。

## 工程计划

- [x] 新增独立图片任务记录与 localForage 仓储，任务业务状态不使用 localStorage。
- [x] 请求快照采用显式参数白名单；渠道/接口/模型脚本只保存指纹，不保存密钥或完整配置。
- [x] 新建任务必须确认持久化后才提交；逐张更新串行落盘，部分成功与失败分开表示。
- [x] 执行与页面组件生命周期分离；导航不丢任务，刷新不自动重新提交，未结束结果标为中断待核对。
- [x] 利用浏览器 Web Locks 和跨标签页通知，避免错误恢复仍在执行的任务。
- [x] 图片工作台新生成/失败重试/Agent 生成统一接入；原始历史继续可读。
- [x] 新增任务记录页、导航入口、搜索/状态筛选、详情、原参数重试、下载与素材复用。
- [x] 图片资源清理纳入任务引用，不因删除别的素材而破坏生成记录。
- [x] 更新变更日志、待测清单、剩余迁移待办，执行自动化与截图验收。最终 24/24 通过，详见同目录验收文档。

## 多维度对抗审查

| 攻击条件 | 设计裁决 | 验收方式 |
| --- | --- | --- |
| IndexedDB 不可用但 Provider 收费成功 | 提交前持久化失败必须阻断 API 请求 | 注入仓储写入错误，断言零请求 |
| 极速双击/页面重新挂载 | 同步提交互斥，执行器独立于组件 | 双提交流程、跨页返回 |
| 一张成功一张失败 | 保存每个槽位，终态 partial，失败信息保留 | 批量拦截响应 |
| 改了提示词/参数再重试 | 读取旧请求快照，新 ID 关联旧任务 | 检查第二次请求体 |
| 渠道移除/地址或脚本改变 | 指纹不符拒绝重试，不静默切别的服务；密钥轮换允许 | 变更渠道后请求计数不增加 |
| API 报错回显密钥 | 错误文本对当前已配置密钥脱敏，快照无凭据字段 | 搜索持久化 JSON |
| 页面刷新，Provider 可能仍执行 | 标为中断，不自动重发，不谎称 Provider 失败/已取消 | 刷新且只出现原一次提交 |
| 另一个标签页仍在运行 | 原执行持有 Web Lock，其他标签页不能恢复该记录 | 双页测试 |
| 并发结果写入互相覆盖 | 每任务串行提交更新，状态由槽位推导 | 批量并发与刷新后计数 |
| 结果保存失败 | 保留内存证据与明确存储错误，提供重新保存；不自动重跑 Provider | 终态落盘错误注入 |
| 素材清理删掉结果 | 任务引用参加资源存活检查 | 清理后刷新图片可见 |
| 图片工作台新/旧两套历史互相干扰 | 新任务是独立权威记录，旧历史只读/保留原操作，删除不连带媒体 | 老记录与新任务共存 |
| 任务页变为漂亮但空的壳 | 所有按钮接入真实本地数据和原 Provider 请求流程 | UI 路由与结果下载/复用 |
| 手机溢出/长错误/暗色不可读 | 扁平分区、固定缩略图、长内容换行、主题 token | 1440 / 390 / 390x568 截图 |
| 远程图片可预览但无法跨域下载 | 记录远程引用但明确标注尚未本地保存，不假称离线留存 | fetch 失败 / img 成功的受控测试 |
| 所有槽位已保存、最终状态写失败 | 依据已保存槽位恢复终态，而不是一概标为中断 | 仅终态写失败注入 |
| 慢读取与执行完成交错 | 递增修订号拒绝旧快照覆盖；读取中的变更通知触发后续刷新 | 人为延迟仓储读取并在中途完成任务 |

审查结论：先实现图片工作台完整闭环。不要一轮同时重写 3500 行画布执行器和视频轮询，否则无法可信验收。
视频恢复混用当前渠道、画布 GenerationRun、资产版本和生产交付仍列后续待办。

## 验收边界

使用独立 Playwright 上下文和受控 Provider 响应，真实 UI、真实 IndexedDB、真实图片解码/存储。
此验证证明应用链路，不证明用户实际 Provider 成功或 Agnes 视频协议正确。
